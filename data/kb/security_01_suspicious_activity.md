# Category: security
# Title: Suspected unauthorized account access

If a customer reports suspicious activity (logins from unfamiliar locations, unexpected changes),
this is a security-sensitive ticket and should never be resolved purely by support chat reassurance.
Immediate steps: force-expire all active sessions for the account (Settings > Security > Sign out
all devices, or the internal admin equivalent), prompt an immediate password reset, and check the
account's login history for anomalies. Any confirmed unauthorized access must be escalated to the
security team regardless of whether the customer seems satisfied with the immediate fix.
