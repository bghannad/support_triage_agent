# Category: technical
# Title: Application running slowly

Performance complaints are usually tied to workspace size — accounts with more than ~50,000 items
in a single workspace can see slower search/load times, a known scaling limitation being worked
on. Ask for workspace size and whether slowness is specific to one view (e.g. a large table) or
global. Browser-based slowness should also rule out browser extensions (ad blockers have caused
rendering issues before) by testing in an incognito window. Do not promise a specific performance
fix timeline — this is a known limitation, not a bug with an ETA.
