# Category: security
# Title: Data privacy / deletion requests

Requests to delete all personal data (distinct from a routine account cancellation) fall under
GDPR/CCPA obligations and must be routed to the privacy/legal escalation queue, not closed at the
support level. Support should acknowledge the request, confirm identity, and set expectations
(typically processed within 30 days per policy) rather than attempting to perform the deletion
directly. Never confirm data has been fully deleted without confirmation back from the privacy
team.
